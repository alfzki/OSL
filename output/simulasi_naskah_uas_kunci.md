## BAGIAN B: SOLUSI LENGKAP STUDI KASUS & HITUNGAN (BOBOT 40%)

### PEMBAHASAN SOAL 1: KETENAGAKERJAAN & KEMISKINAN FGT (20%)

#### 1. Perhitungan Indeks Kemiskinan FGT ($P_0, P_1, P_2$)
Diketahui:
- Total populasi: $n = 20$
- Garis Kemiskinan: $Z = 500.000$
- Jumlah penduduk miskin ($y_i < Z$): $q = 5$ orang
- Rincian pengeluaran penduduk miskin:
  - $y_1 = 200.000 \rightarrow (Z - y_1)/Z = (500.000 - 200.000) / 500.000 = 0,60$
  - $y_2 = 300.000 \rightarrow (Z - y_2)/Z = (500.000 - 300.000) / 500.000 = 0,40$
  - $y_3 = 350.000 \rightarrow (Z - y_3)/Z = (500.000 - 350.000) / 500.000 = 0,30$
  - $y_4 = 400.000 \rightarrow (Z - y_4)/Z = (500.000 - 400.000) / 500.000 = 0,20$
  - $y_5 = 450.000 \rightarrow (Z - y_5)/Z = (500.000 - 450.000) / 500.000 = 0,10$

Langkah Hitung:
- **Headcount Index ($P_0$)**:
  $$P_0 = \frac{q}{n} = \frac{5}{20} = 0,2500 \quad (25,00\%)$$
- **Poverty Gap Index ($P_1$)**:
  $$\sum_{i=1}^5 \left( \frac{Z - y_i}{Z} \right) = 0,60 + 0,40 + 0,30 + 0,20 + 0,10 = 1,60$$
  $$P_1 = \frac{1}{n} \sum_{i=1}^5 \left( \frac{Z - y_i}{Z} \right) = \frac{1,60}{20} = 0,0800$$
- **Poverty Severity Index ($P_2$)**:
  $$\sum_{i=1}^5 \left( \frac{Z - y_i}{Z} \right)^2 = (0,60)^2 + (0,40)^2 + (0,30)^2 + (0,20)^2 + (0,10)^2$$
  $$= 0,36 + 0,16 + 0,09 + 0,04 + 0,01 = 0,66$$
  $$P_2 = \frac{1}{n} \sum_{i=1}^5 \left( \frac{Z - y_i}{Z} \right)^2 = \frac{0,66}{20} = 0,0330$$

#### 2. Klasifikasi Ketenagakerjaan, TPAK, dan TPT
- **Penduduk Usia Kerja (PUK 15+)** = 16 orang.
- **Bekerja**:
  - Bekerja penuh ($\ge 35$ jam) = 10 orang.
  - Setengah penganggur (< 35 jam + cari kerja) = 2 orang.
  - Pekerja paruh waktu (< 35 jam + tidak cari kerja) = 1 orang.
  - Total Bekerja = $10 + 2 + 1 = 13$ orang.
- **Pengangguran Terbuka** (tidak bekerja & melamar) = 1 orang.
- **Angkatan Kerja (AK)** = Bekerja + Pengangguran = $13 + 1 = 14$ orang.
- **Bukan Angkatan Kerja (BAK)** (sekolah penuh waktu) = 2 orang.
- **Tingkat Partisipasi Angkatan Kerja (TPAK)**:
  $$\text{TPAK} = \frac{\text{Angkatan Kerja}}{\text{PUK (15+)}} \times 100\% = \frac{14}{16} \times 100\% = 87,50\%$$
- **Tingkat Pengangguran Terbuka (TPT)**:
  $$\text{TPT} = \frac{\text{Pengangguran Terbuka}}{\text{Angkatan Kerja}} \times 100\% = \frac{1}{14} \times 100\% = 7,14\%$$

### PEMBAHASAN SOAL 2: PRODUKSI, IHK MODIFIED LASPEYRES, & NTP (20%)

#### 1. Estimasi Ubinan Padi Pak Joko
- Luas plot ubinan: $2,5\text{ m} \times 2,5\text{ m} = 6,25\text{ m}^2$.
- Faktor konversi ke Hektar: $\frac{10.000\text{ m}^2}{6,25\text{ m}^2} = 1.600$.
- Produktivitas per Hektar:
  $$\text{Produktivitas (kg/Ha)} = 5,25\text{ kg} \times 1.600 = 8.400\text{ kg/Ha}$$
  $$\text{Produktivitas (Ku/Ha)} = \frac{8.400}{100} = 84,00\text{ Ku/Ha}$$
- Total Estimasi Produksi Sawah (Luas 1,5 Ha):
  $$\text{Total Produksi (Ku)} = 84,00\text{ Ku/Ha} \times 1,5\text{ Ha} = 126,00\text{ Ku}$$
  $$\text{Total Produksi (Ton)} = \frac{126,00}{10} = 12,60\text{ Ton GKP}$$

#### 2. Perhitungan IHK Modified Laspeyres & Inflasi Feb 2025
- Rasio Harga Relatif ($P_t / P_{t-1}$):
  - Beras: $14.700 / 14.000 = 1,0500$
  - Minyak Goreng: $16.800 / 16.000 = 1,0500$
  - Telur Ayam: $30.800 / 28.000 = 1,1000$
  - Lainnya: $1,0000$
- Perhitungan Indeks Periode Berjalan ($I_t$):
  $$I_t = \sum \left( \frac{P_t}{P_{t-1}} \times W_{t-1} \right)$$
  $$I_t = (1,05 \times 25,00) + (1,05 \times 15,00) + (1,10 \times 10,00) + (1,00 \times 50,00)$$
  $$I_t = 26,25 + 15,75 + 11,00 + 50,00 = 103,00$$
- Laju Inflasi Month-to-Month (Februari terhadap Januari 2025):
  $$\text{Inflasi } m\text{-to-}m = \frac{103,00 - 100,00}{100,00} \times 100\% = 3,00\%$$

#### 3. Analisis Nilai Tukar Petani (NTP) & NTUP
- Penghitungan Indeks Harga yang Dibayar Petani ($I_b$):
  $$I_b = (60\% \times \text{IKRT}) + (40\% \times \text{BPPBM})$$
  $$I_b = (0,60 \times 112,00) + (0,40 \times 106,00) = 67,20 + 42,40 = 109,60$$
- Nilai Tukar Petani (NTP):
  $$\text{NTP} = \frac{I_t}{I_b} \times 100 = \frac{118,50}{109,60} \times 100 = 108,12$$
- Nilai Tukar Usaha Petani (NTUP):
  $$\text{NTUP} = \frac{I_t}{\text{BPPBM}} \times 100 = \frac{118,50}{106,00} \times 100 = 111,79$$
- **Interpretasi**:
  1. Nilai $\text{NTP} = 108,12 > 100$ menunjukkan bahwa daya tukar harga produk pertanian yang diterima petani meningkat relatif lebih tinggi (18,50%) dibanding kenaikan harga barang konsumsi rumah tangga dan biaya produksi yang dibayar petani (9,60%) dibanding tahun dasar. Kesejahteraan relatif petani membaik.
  2. Nilai $\text{NTUP} = 111,79 > \text{NTP} (108,12)$ mengindikasikan bahwa secara murni usaha tani sangat efisien dan layak (ongkos produksi hanya naik 6,00%), di mana penekan utama yang mempersempit margin kesejahteraan keluarga petani adalah laju kenaikan harga barang konsumsi rumah tangga (IKRT naik 12,00%).

# Direktori Suplemen Materi Eksternal

Direktori ini digunakan untuk menyimpan seluruh berkas, artikel, kutipan web, atau materi tambahan yang diperoleh dari luar berkas resmi perkuliahan.

## Aturan Penggunaan Direktori Suplemen:
1. **Isolasi Ketat**: Berkas di dalam direktori ini **tidak boleh** digabungkan atau dicampurkan ke dalam direktori `materials/` atau `extracted/`.
2. **Pelabelan Wajib**: Setiap konsep, definisi, atau fakta yang bersumber dari berkas di direktori ini **wajib diberi tanda `[SUPLEMEN]`** dalam bank soal, modul ajar, atau rangkuman.
3. **Hierarki Paling Rendah**: Apabila terdapat perbedaan data atau definisi antara materi resmi dosen/silabus dengan materi di folder ini, maka materi resmi dosen/silabus yang wajib digunakan sebagai acuan jawaban utama.
